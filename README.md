# Попутчики Молдова | ПМР | UA | EU

Telegram-бот (@MI_transferBot), который соединяет водителей и пассажиров. Заявки он берёт из групп попутчиков в Telegram и из объявлений, созданных прямо в боте.

- 🚗 **Водитель** получает людей, которые **ищут машину**, и может разместить объявление «есть свободная машина». Доступ платный: 7 дней бесплатно, дальше продление командой `/grant`.
- 🙋 **Пассажир** получает **свободные машины** по своему маршруту и может разместить заявку «хочу поехать». Бесплатно.
- 🔎 **Лента актуальных объявлений.** Сюда попадают и сообщения, написанные до того, как человек открыл бота: при запуске бот загружает историю групп за 24 часа. Заявки на будущее время, например «на 19:00», видны до отъезда плюс ещё час. Прошедшие скрываются. Без указанного времени заявка висит 4 часа, со словом «сейчас» — 2 часа.

## Пассажир: «🔎 Свободные машины сейчас»

Пассажир выбирает «откуда → куда» (или сохранённый маршрут ⭐, или «Все свободные машины») и получает подходящих водителей. Если актуальных меньше 5, бот добавляет прошедшие объявления по этому маршруту за последние 30 дней (`RIDES_KEEP_DAYS`) с пометкой «🕓 прошедшее — уточните у водителя». Одинаковые ежедневные объявления одного водителя показываются один раз. Под списком есть кнопка «🔔 Присылать новые машины по этому маршруту».

## Фильтры (у водителя и у пассажира)

- 📍 **Откуда → куда.** «➕ Добавить фильтр» сразу спрашивает два города (или «Любой город» / «Куда угодно»). Направление бот определяет сам и пишет его в названии фильтра: Кишинёв → Бельцы — «по Молдове», Кишинёв → Рыбница или Каменка — «Молдова → ПМР», Тирасполь → Одесса — «ПМР → Украина».
- **Совпадение строгое.** Каждый город фильтра должен быть в заявке. Под «Кишинёв ⇄ Тирасполь» не попадут «Кишинёв → Рыбница» и «Кто едет из Кишинёва?» без второго города. Близкие места подходят: Тирасполь — это ещё Бендеры, Парканы, Слободзея; Кишинёв — аэропорт, Яловены (радиус `RIDES_NEARBY_KM`, по умолчанию 25 км). «Туда и обратно» ловит и обратный маршрут.
- 🗺 **Целый регион** (кнопка на первом шаге): Вся Молдова, Только ПМР, Украина, Европа, Все заявки. Ранее созданные фильтры продолжают работать.

Бот понимает русский и румынский, отличает пассажира («ищу машину», «кто едет», «caut loc») от водителя с местами и от рекламы, а одинаковые заявки из разных групп присылает один раз. У водителя 7 дней бесплатно, потом админ продлевает доступ командой `/grant`.

## Переменные в Railway (Service → Variables)

| Переменная | Обязательно | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather. **Не храните его в коде**: репозиторий публичный |
| `BOT_NAME` | нет | название бота, по умолчанию «Попутчики Молдова \| ПМР \| UA \| EU». Бот ставит его себе сам при запуске |
| `DATABASE_URL` | да | PostgreSQL (Railway подставляет автоматически) |
| `ADMIN_CHAT_ID` | нет | ваш Telegram ID, по умолчанию 1657186014. Можно несколько через запятую |
| `TG_API_ID`, `TG_API_HASH` | для заявок | с https://my.telegram.org для **отдельного** аккаунта-читателя |
| `TG_SESSION` | для заявок | строка сессии аккаунта-читателя, см. ниже |
| `INGEST_KEY` | для Viber | секретный ключ для приёма уведомлений с телефона |
| `VIBER_GROUPS` | нет | слова из названий Viber-групп через запятую, по умолчанию `попутчики_md,попутчики приднестровье,по пути на юг молдовы` |
| `VIBER_LINKS` | нет | ссылки-приглашения на Viber-группы для кнопки «🔗 Группа в Viber»: `попутчики_md=https://invite.viber.com/?g2=…; попутчики приднестровье=https://…` |
| `RIDES_WEB` | нет | сайты: `makler` (по умолчанию) или пусто, чтобы выключить |
| `RIDES_BACKFILL_HOURS` | нет | за сколько часов загружать историю групп при запуске, по умолчанию 24 |
| `RIDES_SOURCES` | нет | дополнительные группы через запятую, например `poputchik_pmr,odessa_palanka` |
| `RIDES_TRIAL_DAYS` | нет | пробный период, по умолчанию 7 |
| `RIDES_KEEP_DAYS` | нет | сколько дней хранить прошедшие объявления для поиска машин, по умолчанию 30 |
| `RIDES_PAYMENT_TEXT` | нет | текст про оплату в «Помощи», например «150 лей/мес, писать @ваш_ник» |

Если `TG_*` не заданы, меню бота работает, но заявки не приходят.

## Как получить TG_SESSION (один раз, на своём компьютере)

1. Заведите отдельный Telegram-аккаунт для чтения групп, лучше на запасной SIM. Основной аккаунт не используйте.
2. Войдите этим аккаунтом на https://my.telegram.org → **API development tools** и получите `api_id` и `api_hash`.
3. На компьютере с Python выполните:
   ```
   pip install telethon
   python make_session.py
   ```
   Введите API_ID, API_HASH, номер телефона и код из Telegram. Скрипт выведет длинную строку.
4. Вставьте её в Railway в переменную `TG_SESSION`, а `api_id` и `api_hash` — в `TG_API_ID` и `TG_API_HASH`. **Никому не показывайте эту строку**: она даёт полный доступ к аккаунту.

## Источники: группы и сайты

**Группы Telegram.** Аккаунт-читатель сам вступает в группы и читает их в реальном времени.
- `/findgroups`: бот ищет публичные группы попутчиков в Telegram по двум десяткам запросов (попутчики, попутка, такси Кишинёв, Бельцы, Комрат, caut transport и т.д.) и показывает их с числом участников. Группа добавляется кнопкой «➕», сразу, без перезапуска, вместе с историей за 24 часа.
- `/findgroups бельцы такси`: поиск по своему запросу.
- `/addsource @группа` или ссылка `https://t.me/...` (в том числе приглашение в закрытую группу `https://t.me/+...`).
- `/sources`: список того, что читает бот. Добавленные из бота группы удаляются здесь же.
- Постоянный список лежит в `rides/sources.txt` и переменной `RIDES_SOURCES`.

Telegram ограничивает частые вступления в группы. Если бот ответит «просит подождать N с», добавляйте группы понемногу.

**Сайты.** `makler.md` → «Пассажирские перевозки», проверка раз в 10 минут (`RIDES_WEB_INTERVAL`). Там почти только перевозчики и такси. Их объявления показываются пассажирам в ленте «Свободные машины» с пометкой «перевозчик» после обычных водителей. Уведомлениями они не рассылаются: перевозчики поднимают объявления каждый час. Выключить: `RIDES_WEB=` (пусто).

**Viber и другие чаты, которые бот не читает сам.** Команда `/paste Название группы` включает режим вставки: копируйте сообщения из Viber (или пересылайте из любого чата Telegram) в бота. Каждое сообщение становится заявкой: попадает в ленту и уходит по фильтрам, а телефон из текста сохраняется. Выход из режима: `/done`.

**Viber-группы через Android-телефон.** Viber не даёт читать группы напрямую, поэтому их уведомления пересылает телефон (например, через приложение MacroDroid) на адрес бота:
`POST https://<домен-railway>/ingest?key=<INGEST_KEY>` с полями `title` (заголовок уведомления) и `text` (текст уведомления), в JSON, форме или прямо в адресе.
- `INGEST_KEY` — секретный ключ, задаётся в Railway. Без него приём выключен.
- Viber сворачивает сообщения группы в сводку «Новые сообщения в …», поэтому передавайте ещё `lines` (строки текста уведомления) и/или `big` (развёрнутый текст): каждая строка «Автор: текст» обрабатывается как отдельное сообщение. Диагностика: `/ingestlog`.
- `VIBER_GROUPS` — какие уведомления брать: слова из названия группы через запятую, по умолчанию `попутчики_md,попутчики приднестровье,по пути на юг молдовы`. Личные переписки в бот не попадают.
- Заявки из Viber появляются в ленте с пометкой «Viber · название группы» и именем автора и рассылаются по фильтрам.
- Ссылку на конкретное сообщение Viber не даёт, поэтому кнопка ведёт на саму группу: «🔗 Группа в Viber». Ссылки задаются в `VIBER_LINKS` (в Viber: группа → «Поделиться ссылкой»). Кнопка появляется и у уже загруженных заявок.

999.md не подключён: объявления там подгружаются скриптом, а для официального API нужен партнёрский ключ. Facebook и Viber не читаются автоматически: у Viber нет такой возможности, а правила Facebook это запрещают.

## Команды

| Кто | Команда | Что делает |
|---|---|---|
| все | `/start` | выбор роли (водитель или пассажир) и главное меню |
| все | `/myid` | показать свой Telegram ID |
| админ | `/findgroups [запрос]` | найти группы попутчиков в Telegram и добавить кнопкой |
| админ | `/addsource @группа` | добавить группу по ссылке |
| админ | `/sources` | что читает бот, удалить группу |
| админ | `/paste Название` … `/done` | вставлять заявки из Viber вручную |
| админ | `/stats` или `/stats 30` | заявки за 7 или 30 дней: по типам, группам, маршрутам |
| админ | `/grant 123456789 30` | продлить водителю доступ на 30 дней после оплаты |

## Структура

- `bot.py` — запуск, название и описание бота.
- `make_session.py` — получение `TG_SESSION`.
- `rides/handlers.py` — меню бота: роли, лента, свои объявления.
- `rides/posts.py` — объявление: сборка и карточка.
- `rides/timeparse.py` — время поездки и срок актуальности.
- `rides/listener.py` — чтение групп.
- `rides/parsing.py` — разбор сообщений.
- `rides/places.py` — города Молдовы и ПМР.
- `rides/filters.py` — логика фильтров.
- `rides/notifier.py` — рассылка водителям.
- `rides/db.py` — таблицы в PostgreSQL.
- `rides/sources.txt` — постоянный список групп.
- `rides/web.py` — объявления с makler.md.
