# TransferMD_BOT

Telegram-бот с двумя разделами:

1. **Заказ трансфера**: Mini App (`index.html`). Клиент выбирает маршрут и авто, заказ сохраняется в PostgreSQL и приходит администратору.
2. **🚕 Заявки попутчиков для водителей**: бот читает группы попутчиков в Telegram и присылает водителю людей, которые ищут машину по его маршруту. Так водитель не едет пустым.
   Вход: кнопка «Я водитель» после `/start` или команда `/driver`.

## Фильтры водителя

- 🛣 **Маршрут откуда → куда**: например «Бендеры ⇄ Кишинёв» или «любой → Бельцы». Можно в обе стороны или только в одну.
- 🇲🇩 **Вся Молдова**: любая заявка, где есть город Молдовы.
- 🔴 **Только ПМР**: Тирасполь, Бендеры, Рыбница, Дубоссары, Слободзея и др.
- 🌍 **Все заявки**.

Бот понимает русский и румынский, отличает пассажира («ищу машину», «кто едет», «caut loc») от водителя с местами и от рекламы, а одинаковые заявки из разных групп присылает один раз. У водителя 7 дней бесплатно, потом админ продлевает доступ командой `/grant`.

## Переменные в Railway (Service → Variables)

| Переменная | Обязательно | Что это |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather. **Не храните его в коде**: репозиторий публичный |
| `DATABASE_URL` | да | PostgreSQL (Railway подставляет автоматически) |
| `ADMIN_CHAT_ID` | нет | ваш Telegram ID, по умолчанию 1657186014. Можно несколько через запятую |
| `TG_API_ID`, `TG_API_HASH` | для заявок | с https://my.telegram.org для **отдельного** аккаунта-читателя |
| `TG_SESSION` | для заявок | строка сессии аккаунта-читателя, см. ниже |
| `RIDES_SOURCES` | нет | дополнительные группы через запятую, например `poputchik_pmr,odessa_palanka` |
| `RIDES_TRIAL_DAYS` | нет | пробный период, по умолчанию 7 |
| `RIDES_PAYMENT_TEXT` | нет | текст про оплату в «Помощи», например «150 лей/мес, писать @ваш_ник» |
| `WEB_APP_URL` | нет | адрес Mini App, по умолчанию текущий railway.app |

Если `TG_*` не заданы, раздел для водителей в боте работает, но заявки не приходят.

## Как получить TG_SESSION (один раз, на своём компьютере)

1. Заведите отдельный Telegram-аккаунт для чтения групп, лучше на запасной SIM. Основной аккаунт не используйте.
2. Войдите этим аккаунтом на https://my.telegram.org → **API development tools** и получите `api_id` и `api_hash`.
3. На компьютере с Python выполните:
   ```
   pip install telethon
   python make_session.py
   ```
   Введите API_ID, API_HASH, номер телефона и код из Telegram. Скрипт выведет длинную строку.
4. Вставьте её в Railway в переменную `TG_SESSION`, а `api_id` и `api_hash` — в `TG_API_ID` и `TG_API_HASH`. **Никому не показывайте эту строку**: она даёт полный доступ к аккаунту.

## Группы

Группы перечислены в `rides/sources.txt`, сейчас там `t.me/poputchik_pmr`. Новые группы можно добавить в этот файл или в переменную `RIDES_SOURCES`. Аккаунт-читатель сам вступает в открытые группы (чтобы выключить это, задайте `RIDES_AUTO_JOIN=0`).

## Команды

| Кто | Команда | Что делает |
|---|---|---|
| все | `/start` | заказ трансфера и кнопка «Я водитель» |
| все | `/driver` | меню водителя: фильтры, пауза, что присылать |
| все | `/myid` | показать свой Telegram ID |
| админ | `/stats` или `/stats 30` | заявки за 7 или 30 дней: по типам, группам, маршрутам |
| админ | `/grant 123456789 30` | продлить водителю доступ на 30 дней после оплаты |

## Проверка распознавания заявок

```
python -m rides.test_parsing
```

## Структура

- `bot.py` — запуск, заказ трансфера и веб-сервер Mini App.
- `index.html` — Mini App.
- `make_session.py` — получение `TG_SESSION`.
- `rides/handlers.py` — меню водителя.
- `rides/listener.py` — чтение групп.
- `rides/parsing.py` — разбор сообщений.
- `rides/places.py` — города Молдовы и ПМР.
- `rides/filters.py` — логика фильтров.
- `rides/notifier.py` — рассылка водителям.
- `rides/db.py` — таблицы в PostgreSQL.
- `rides/sources.txt` — список групп.
